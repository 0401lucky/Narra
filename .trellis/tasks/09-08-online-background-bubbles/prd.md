# 2.2.12-dev 线上背景玻璃气泡开关

## Goal

全局作用于线上聊天，默认开启；关闭后保留背景图与所选主题气泡，线下不受影响。

版本为 2.2.12-dev。来源和已确认决策以[父任务 PRD](../09-08-roleplay-moments-ui-feedback/prd.md)的 R1 为准；本子任务拥有 A1、A2、A3、A4、A9。

## Requirements

- 在现有主题与气泡设置中提供“线上背景玻璃气泡”开关，并清楚标明全局作用于线上聊天。
- 默认开启，旧配置升级后保持原有有背景玻璃气泡效果。
- 关闭后继续显示背景图，双方普通对话气泡使用所选主题及已有宽度、圆角、内边距和尾巴设置。
- 适用于所有线上场景，包括线上心声模式和群聊；线下模式及无背景的主题表现保持原有行为。
- 沿用现有设置保存交互；保存成功后跨场景及重启保留选择，失败时使用原有失败反馈。
- 调整主题或重置旧气泡样式不意外改变独立开关；页面背景、顶部栏、时间标识和输入区继续沿用原有外观。

## Acceptance Criteria

- [x] 默认状态和不含新字段的旧配置都开启玻璃效果。
- [x] 关闭并保存后，带背景的线上用户 / 角色气泡恢复主题颜色、形状、宽度与普通主题渲染外壳。
- [x] 开启后恢复现有玻璃效果，所选背景和自定义样式值未被清除。
- [x] 切换其他线上场景、重新打开应用后保留选项；保存失败不误报成功。
- [x] 线下模式、有 / 无背景及背景加载失败的回退与父任务 A4、A9 一致。
- [x] 主题切换、样式重置、引用、流式文字和错误提示仍正常，文字对比度可读。
- [x] 相应配置、模型、保存协调和设备 UI 验证完成，结果可追溯。

## Out of Scope

- 朋友圈改动、按角色分别保存开关、所有线上页面统一重做、专用图片 / 转账 / 礼物卡片重设计。
- 修改 Room schema、API 协议、权限或发包更新源。
