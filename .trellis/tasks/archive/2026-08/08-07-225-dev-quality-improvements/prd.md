# 2.2.5-dev 稳定性与可用性修复

## Goal

在 2.2.5-dev 中完成三项可独立验证的功能修复：提高群聊多角色回复可靠性，修复
角色音色配置弹窗无法滚动，并为普通聊天与 RP 提供一致的单条消息删除能力。

应用性能基准与优化已按用户决定拆为独立专项，后续单独进行全量测试、分析和优化，
不再作为本轮交付依赖。

## Background and confirmed facts

- `RoleplaySendActionSupport.kt:1088-1225` 已按回复回合串行执行并提供单角色最多两次
  尝试；主要风险是已完成正文被后处理异常覆盖，以及 RoundTrip 外异常缺少发送终态
  兜底。
- `VoiceSynthesisSettingsScreen.kt:715` 的角色音色 Sheet 在 `:786` 使用不可滚动的
  `Column`，保存按钮位于 `:949`。
- 普通聊天和 RP 当前都没有物理删除入口；两者共用 `ChatMessage`、
  `ConversationRepository` 和 Room 消息存储，可以共享同一删除契约。

## Requirements

### R1：群聊多角色回复可靠性

- 保留现有串行回合顺序和单角色有界重试。
- 一个角色最终失败不得丢失其他角色的成功回复或阻断后续角色。
- 模型正文完成持久化后，协议、脚本、观察等后处理失败不得把正文覆盖为 ERROR。
- 异常、取消、切换场景或会话后，Loading、`isSending`、流式状态和持久化快照必须
  回到一致终态。

### R2：角色音色配置页可用性

- 角色音色 Sheet 在小屏、大字体、长文本、克隆错误和输入法出现时可垂直滚动。
- “测试”“取消”“保存”等操作可通过滚动访问，并避开导航栏和输入法遮挡。
- 不改变草稿、试听、样本复制/删除和设置持久化语义。

### R3：单条消息删除

- 普通聊天与 RP 都提供独立、不可逆的物理删除入口和二次确认。
- RP 原有“撤回”继续保留；一个底层 RP 消息对应的多个派生气泡统一删除。
- 同一 Room 事务删除目标消息、全部来源记忆、会话摘要与摘要分段，并清除其他消息
  顶层及 parts 中指向目标的 `replyTo*` 元数据。
- 删除消息记录不删除本地附件文件；发送中、流式中和 `LOADING` 消息禁止删除。

## Scope

### In scope

- 三项功能涉及的 UI、ViewModel、Support/Coordinator、Repository/Store、Room DAO、
  单元测试和设备/Compose 测试。
- 2.2.5-dev 版本记录文档同步，以及三项功能完成后的跨层集成回归。

### Out of scope

- 应用性能基准、Trace 分析、Baseline Profile 生成和热点优化；这些已拆为独立任务。
- 更换 AI Provider、群聊导演策略、并行发送或全局网络重试。
- Room Paging、数据库 schema 改造、附件文件垃圾回收或批量消息删除。
- 正式 release 签名、强制更新和生产发布。

## Acceptance Criteria

- [ ] **PAC1**：群聊至少两名角色在正常、瞬时 5xx、部分失败、全部失败、后处理异常、
      取消和切换场景/会话时都有明确终态，不出现永久 Loading 或旧 run 串写。
- [ ] **PAC2**：音色 Sheet 在代表性小屏和大字体设备上可滚动到并点击保存，输入法和
      导航栏不造成操作永久不可达，既有草稿与试听行为不变。
- [ ] **PAC3**：普通聊天与 RP 均可二次确认后删除单条底层消息；消息、引用、来源
      记忆、摘要和分段原子清理，附件文件保留，RP 撤回仍独立可用。
- [ ] **PAC4**：三个子任务分别通过窄测和质量检查；父任务完成全量 JVM 单测、Lint、
      debug 构建及可执行的设备测试，并同步 2.2.5-dev 版本文档。

## Task map

- `08-07-group-chat-reply-reliability`：P0，群聊失败链路和状态恢复。
- `08-07-voice-profile-sheet-scroll`：P1，角色音色 Sheet 滚动与安全区。
- `08-07-single-message-delete`：P1，普通聊天/RP 删除入口和原子关联清理。

独立专项：`08-07-app-performance-optimization`，已解除父子关系，目标版本待定。

## Finalized decisions

- 当前实现版本固定为 `2.2.5-dev`，本轮只交付群聊、音色滚动和单条删除。
- 性能任务后续独立开展全量基准、测试与优化，不阻塞本轮三项功能。
- 群聊保留串行回合和最多两次尝试，不引入新的并发或全局重试。
- 单条删除同时覆盖普通聊天与 RP；RP 撤回保留。
- 删除采用同一 Room 事务关联清理，不删除本地附件文件，不修改 Room schema。
