# v2.4.1 陪伴 D5：语音与朗读控制

## 目标与归属

把已配置MiMo和角色音色接到陪伴台词，以可停止、可缓存、可翻译和可收藏的声音体验保持文字和用户控制。

父任务为 [完整陪伴升级](../11-09-date-companion/prd.md)，版本固定2.4.1，承接 N8；AC10及AC3资源语义。用户已确认升级现有线下扮演和完整规划；完整方案已于2026-11-09获实施批准；按前置依赖由主会话激活，当前状态见task.json。

## 前置与边界

前置：[D4](../11-09-date-companion-stage-reading/prd.md) 已通过独立验收并提供对应接口/验证证据。父任务的记忆/身份/版本/入口/范围外条款同样适用；依赖不由任务树顺序隐含。

## 需求

- **D5-R1**：陪伴语音/自动播默认关闭，与旧VOICE_MESSAGE后台合成独立；缺配置不阻塞文字，默认自动播只台词、不自动读开场。
- **D5-R2**：点播、可选逐句自动播、按所选跨场次顺序连续朗读使用同一SpeechUnit；选中旁白可读，控制协议不出声。
- **D5-R3**：可选翻译复用TRANSLATION用途，原文不改；失败可重试或显式读原文，不静默换语言。
- **D5-R4**：统一所有缓存层的有效参数键，覆盖文本、语种、端点/模型、角色音色/克隆内容版本与声学参数。
- **D5-R5**：会话级音频owner统一取消翻译/合成/队列/播放器；换句/模式/角色/离场拒绝迟到结果，失败/取消不缓存成功。
- **D5-R6**：独立收藏保存实际音频/文本/语言/来源版本；生成收藏费用明确，清缓存、删源、取消收藏分别处理。
- **D5-R7**：当前MiMo整段响应与分段朗读如实交付；不新增供应商或声称PCM增量/逐字音频时钟字幕。

## 验收标准

- [x] **D5-AC1**：关闭/缺Key/缺音色零隐式合成，只有播放器真正开始后才报告播放；所有失败保留文字。
- [x] **D5-AC2**：同文不同语言/模型/音色/克隆版本缓存不串；合法已持久音频挂接失败可补存且不重合成。
- [x] **D5-AC3**：旧翻译/网络/prepared在换句/离场后不能出声；长文分段停止不继续队列，残缺文件不成成功缓存。
- [x] **D5-AC4**：选区含旧场次和旁白时内容/顺序准确；原文与译文对应，翻译失败行为明确。
- [x] **D5-AC5**：收藏已有音频零调用；生成收藏明确执行；清缓存跳过收藏、删源保留收藏并标失效、取消收藏不删原文。

2026-11-19工程验收：JVM分轮按class+method最新去重107/107（15类），隔离AVD设备8/8（6真实Compose/1本地WAV原生播放器/1固定55升级），main/JVM/AndroidTest与baseline编译、dev/test APK、Lint通过。原命令/报告/SHA与逐AC证据见 [handoff](research/handoff.md) 和 [独立检查](research/check.md)。真实MiMo质量、物理设备音效与视觉接纳单列未测，不把Fake当供应商效果；D4旧34截图差异保留未接纳。

本块验收对应父 [44+8项矩阵](../11-09-date-companion/acceptance-matrix.md) 的本块行；不能用已有测试文件存在或其它块通过代替本块结果。

## 兼容与范围外

既有语音消息音频仍是历史产物，改音色不自动覆盖；新陪伴开关不反向开启旧后台合成。MiMo能力之外不假定emotion标签受支持，按现有有效参数清洗/保留，不读出控制标记。
