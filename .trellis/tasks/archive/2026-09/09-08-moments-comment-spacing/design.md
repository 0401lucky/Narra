# 朋友圈评论预览间距设计

## 布局调整

改动限定在 MomentsScreen.kt 的 MomentEngagementBlock；数据、回调与最多四条预览规则保持原样。

| 项目 | 当前值 | 设计值 |
| --- | --- | --- |
| 评论预览行高度 | 显式最小 48dp | 按文字与局部内边距自然增高 |
| 每条评论上下内边距 | 各 8dp | 各 2dp |
| 容器条目间距 | 8dp | 4dp |
| 整个评论块内边距 | 8dp | 保留 |
| 预览最大行数 | 2 行 | 保留 |

使用此组件内的局部尺寸，不修改共享 NarraUi.compactGap 或 NarraMinimumTouchTarget。使用自然高度而非固定更小行高，保证多行评论与放大字体仍有足够空间。

## 交互与可访问性

保留每条评论的 fillMaxWidth、combinedClickable、语义 test tag、长按震动和删除确认回调。继续显式保留单击进入详情，避免长按手势拦截后丢失点击。

移除的是显式最小视觉行高，不降低全局 ViewConfiguration 或 Material 触控配置。Compose 自身的触控扩展保持原样；相邻预览必须在其可见文字区域正确命中，设备用例验证顶部、中间及末尾的不同评论，不假定删除高度约束后手势一定正常。

点赞按钮、查看全部评论按钮以及详情页操作继续使用原有触控尺寸。本需求不要求把所有可交互元素压缩成紧凑行。

## 测试调整

MomentsScreenTest.kt:255 当前把评论预览至少 48dp 当成要求。将这一处断言改为短评论列表的实际布局密度验收，并保留和加强长按删除确认 / 取消的行为验证；其他按钮的 48dp 断言继续保留。

在默认字体与确定宽度下，以多条短评论的实际布局边界或文字基线间距验证已收紧，不将扩大后的触控边界误当作视觉间距，也不把精确实现常量原样抄成测试。加入两行文字 / 放大字体样例验证内容不重叠，并复核四条预览的实际画面。

## 风险与回退

主要风险是相邻评论触控命中和大字体换行；通过设备布局与手势验证判断。回退范围仅为 MomentEngagementBlock 的尺寸及对应测试，不触及评论数据库或整页重设计。
