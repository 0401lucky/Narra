# 2.2.12-dev 朋友圈评论预览间距

## Goal

收紧时间线评论预览留白，保留单击详情、长按删除及多行文字展示。

版本为 2.2.12-dev。来源为[父任务 PRD](../09-08-roleplay-moments-ui-feedback/prd.md)的 R2，本子任务拥有 A5、A6、A7。

## Requirements

- 只调整朋友圈时间线动态卡片内最多四条评论的预览密度，恢复接近旧版的紧凑阅读效果。
- 短评论按实际文字排布，长评论在现有行数限制内正常换行，保留适量分隔。
- 每条预览单击仍进入帖子详情，长按仍定位该评论并给出原有删除确认；取消不删除。
- 不修改评论正文、生成逻辑、详情页整体布局或全应用触控尺寸。

## Acceptance Criteria

- [x] 默认字体下四条短评论明显紧凑，布局中不再出现当前每条短文字占大块空白的表现。
- [x] 多行评论及放大字体不相互遮挡；姓名与正文仍按原规则展示。
- [x] 单击打开详情；相邻评论分别长按均命中正确评论，删除确认和取消正常。
- [x] 点赞行、查看全部评论、删除流程及原有按钮可用性未退化。
- [x] 相关设备用例包含布局密度和真实手势验证，记录实际执行结果。

## Out of Scope

- 主题气泡开关、评论正文清洗、评论生成 / 删除数据层变更、所有页面触控尺寸调整。
