# 2.2.12-dev 线上聊天背景气泡与朋友圈评论间距反馈

## Goal

让线上角色扮演聊天能够保留背景图和原主题气泡，并收紧朋友圈评论预览的纵向留白。

## Requirements

### R1：线上角色扮演聊天的背景图与玻璃气泡可独立选择

用户明确表示“线上能不能只弄背景，不换气泡”“线下不变”，并接受“搞个开关”。这里的图片指聊天背景图，气泡指聊天消息的透明 / 玻璃效果。

- 在角色扮演的线上手机聊天模式中，提供是否在自定义背景图上使用玻璃气泡的开关。
- 开关全局作用于所有线上聊天，包括线上心声模式与线上群聊；新安装及旧配置升级后默认开启。
- 关闭时，背景图继续显示，用户与角色气泡沿用所选主题及已有气泡自定义设置。
- 开启时，保留当前有背景图时的玻璃气泡效果。
- 线下角色扮演聊天保持原有行为。
- 设置保存成功后，重新进入当前或其他线上聊天均使用所选状态；重启应用后仍保留。
- 未设置背景图或背景图未加载成功时，继续使用原主题气泡。
- 切换开关、切换主题及重置既有气泡样式时，不意外丢失其他独立配置；页面背景、顶部栏和输入区维持原有表现。

修复前核对：该需求对应真实的功能缺口。背景图加载成功后，线上颜色分支自动选择玻璃配色，气泡形状分支也不再使用无背景主题的自定义样式；当时没有独立解除这种关联的开关。

### R2：收紧朋友圈时间线评论预览的纵向间距

用户所说“评论有空格”“那个空的太大了，收紧点点”指 Image #1 中相邻评论之间的纵向留白。

- 收紧朋友圈时间线动态卡片内评论预览的纵向留白，保留适量间隔。
- 单行短评论应形成紧凑的连续列表；长评论应正常换行，不相互遮挡。
- 保留预览评论单击进入详情、长按删除确认以及取消删除的现有行为。
- 不修改评论正文中的空格、换行或其他内容。

修复前核对：预览行叠加了 48dp 最小高度、上下各 8dp 内边距和 8dp 条目间距。这些改动来自 2026-09-07 的界面重设计提交 7b7903a1；此前条目间距为 4dp，预览文字没有上述显式最小高度和上下内边距。用户“这次更新才有”的说法有提交记录支持。

## Acceptance Criteria

- [x] A0：两项反馈已分别对应到用户原话、当前代码和相关证据，用户确认的版本、作用范围与默认行为均已记录。
- [x] A1 / R1：同一线上聊天设有背景图时，开关关闭后背景仍可见，双方气泡保持所选主题原本的颜色和形状。
- [x] A2 / R1：开关开启后恢复当前玻璃气泡效果，切换过程不清除背景或已有气泡自定义配置。
- [x] A3 / R1：默认及旧配置升级时开关开启；保存关闭状态后，重进聊天、切换其他线上聊天和重启应用均保留关闭状态。保存失败沿用现有错误提示，不报告保存成功。
- [x] A4 / R1：切换到线下模式时仍保持线下原有视觉行为。
- [x] A5 / R2：以四条单行评论为样例，预览列表恢复接近旧版的紧凑密度，条目间仍可清楚区分；具体尺寸见子任务设计。
- [x] A6 / R2：较长评论在既有预览行数限制内正常展示，评论之间不重叠、不新增正文空白。
- [x] A7 / R2：单击预览仍能打开详情；长按定位正确评论，确认删除和取消均按原逻辑工作。
- [x] A8：实现阶段完成针对性验证，并更新 2.2.12-dev 的版本记录和实际完成状态。
- [x] A9 / R1：无背景图时不引入视觉变化；关闭开关后气泡配色、形状、宽度及渲染材质均使用主题路径，顶部栏、输入区和背景图不随之改变。
