# v2.3 扩面一：线下扮演与会话阅读

## Goal

将真实线下扮演及既有会话阅读入口扩入 v2.3 默认令牌和无障碍契约，使大字体、读屏与日常操作可用；保留线上试点和个性化行为。归属 [扩面父任务](../10-21-ui-token-accessibility-expansion/prd.md)，2026-10-21 用户在最终摘要后回复“可以”，批准先实施本批。

## Background

真实入口及源码锚点见 [P04 研究](../10-21-ui-token-accessibility-expansion/research/offline-entry.md)：相同 `roleplay/play/{scenarioId}` 路由按 ONLINE_PHONE 与线下分支选择内容，线下包括 OFFLINE_DIALOGUE / OFFLINE_LONGFORM；会话阅读是既有独立路由，不是 P14 日记。B04 线下两张只有组件覆盖，尚无本批整页 / 阅读基准。研究未运行测试，源码风险尚待实际测量。

## Requirements

- O1：线下默认顶栏、对话容器、空态、建议、提议及快捷入口实际消费既有令牌和成对颜色；共享输入 / 气泡优先复用，只为实际失败做必要最小修正。
- O2：对白和长文剧情均保留发送 / 停止、附件、建议、跳转滚动、stable key、顶栏收起 / 恢复及设置回调；不重写状态机或新建业务状态。
- O3：阅读页迁移自身默认几何 / 语义并保持 lineHeight、高对比、系统安全区与既有材质；进入阅读前 P05 保存成功门槛不变，不给阅读页新增皮肤存储。
- O4：保留 13 皮肤、用户气泡几何 / 尾角 / 玻璃开关；真实图片状态及线下忽略线上玻璃开关的谓词不变。实际文字承载面至少 4.5:1。
- O5：320×640dp / 200% 字体下长名、提议、建议与快捷面板的组合不遮挡主要操作，至少一行真实消息正文可读且可滚动到达；消息 viewport 不能只剩几 dp 薄带。独立操作具有效名称 / 角色、至少 48dp 命中并避免相邻误触。
- O6：新增 14 张 E04 页面 / 阅读候选，保留旧基准与守卫；迁移前后有真实证据，人工接纳后再 verify。动态浅深、代表皮肤和错误 / 生成状态用生产布局与行为测试补充。

## Acceptance Criteria

- [x] OA1 / O1：迁移声明有令牌消费与精确例外库存，空态 / 建议 / 正文均按实际绘制面通过主题和对比检查。（宿主受测组合，独立check通过）
- [x] OA2 / O2/O5：真实线下分支的顶栏、发送 / 停止、建议、快捷入口、滚动与大字体布局 / 回调断言通过；对白 / 剧情两种模式均覆盖。（宿主真实组件 / 触控 / 完整正文行）
- [x] OA3 / O3：阅读空态、混排长文、长标题、滚动到底 / 关闭可用；已有 P05 保存成功 / 失败门槛不变。（4项交互与3项配色等回归，导航原文件未改）
- [x] OA4 / O4：P03 共享页面、13 皮肤 / 用户几何和 B01–B04 材质回归通过，无隐式全局改版。（定向63项全绿，旧78图一致）
- [x] OA5 / O6：E04 14 张候选人工确认后，全部已接纳截图及缺图 / 计数门禁通过；所需单测、Lint、dev 构建及受影响 AndroidTest 编译有真实结果。（用户回复“可以，还有任务吗？”接纳14图；93/93真实截图、1677/1677完整JVM通过）
- [x] OA6：报告区分本机 / CI / 设备 / 性能，更新版本记录及必要 spec；本批文件可独立审阅 / 回退。（验证 / check / 前后对照齐备，未接纳 / 提交 / 归档）

## Out of scope

- P05 侧栏整体、P14 日记、其他历史专项；皮肤 / schema / 发送或流式协议变更；重做立绘资产 / 动效或公共玻璃算法。
