# v2.3 设计令牌与无障碍试点

## Goal

为消息首页 / 手机主壳（P01）、角色管理列表（P02）与线上扮演（P03）统一默认形状、间距和语义颜色，补齐读屏、触控与大字体表现，并以现有截图安全网核验变化。完成后提供 v2.3 的后续扩面清单。

## User value

- 三个试点入口使用一致的默认视觉规则，后续修改能沿共享定义生效。
- 放大字体或使用读屏时仍能识别、找到并使用主要操作。
- 用户选择的个性化配置有明确优先级，视觉迁移可审阅、可回退。

- 归属 v2.3；2026-10-21 用户授权创建当前任务，随后选择“统一吧”，并在完整规划摘要与实施批准问题后回复“继续”，批准按该摘要实施。
- [旧试点草案](../archive/2026-10/10-14-ui-token-accessibility-pilot/prd.md) 与 [路线图](../archive/2026-10/10-14-narra-experience-consistency/prd.md) 为来源；当前任务承接旧试点，旧任务及其他性能任务本轮不改状态。

## Requirements

- **T1 统一默认几何**：三处试点均使用 8 / 16 / 24 / 全圆四档默认形状，布局间距使用 4 / 8 / 12 / 16 / 24 / 32 六档。不能只增加令牌定义而保留旧调用；图标几何、边框、零间距等按用途管理。
- **T2 统一默认语义颜色**：三处默认界面（包括 Narra 气泡）均使用应用 Material 颜色角色，对话高亮、旁白、系统提示和错误有明确的文字 / 底色配对。跟随应用实际浅深色及动态颜色；受测阅读文字与合成表面对比度至少 4.5:1。
- **T3 个性化优先级**：保留全部 13 个皮肤选项；Narra 默认配色随 T2 统一，其他明确选择的皮肤仅保留品牌配色和装饰例外，统一语义接口并修正低对比文字。现有圆角、宽度、横纵内边距、尾角和玻璃开关数值原样保留，不擅自取整或改写存储；背景加载 / 开关的材料选择行为保持。
- **T4 无障碍可用**：可操作图标有有效名称，装饰图标不重复朗读；关键目标至少 48dp。修复范围内 P01 底栏裁切、P03 头部遮挡和输入提示溢出，在 320×640dp、200% 字体下主要操作可见或能滚动到达。目标扩展不把紧凑评论改成固定 48dp 行高。
- **T5 新增违规门禁**：对迁移文件建立按用途检查的形状、颜色、间距规则与精确例外清单；不允许目录级豁免、通过移动代码规避或仅按全局数量判定。正反例证明门禁发现新违规，并接受合法图标 / 品牌 / 用户配置表达式。
- **T6 可审阅视觉回归**：保留已确认基准，逐批提供迁移前后和差异图；预期差异经人工确认后才能接纳新基准。缺图、零测试、未登记用例和非预期变化必须失败；CI 继续只 verify。
- **T7 交付与扩面**：汇总迁移范围、例外、遗留问题、验证结果与后续 v2.3 扩面清单。性能或 D01 实际设备效果缺测时明确未验收，不能写成全 App 达标或无性能回归。

## Pilot scope

- P01 消息首页 / 手机主壳中的共享标题、卡片、导航和主要操作。
- P02 角色管理列表中的列表项、空态 / 搜索结果容器和主要操作。
- P03 线上扮演中的头部 / 输入区、消息气泡、主要消息操作和回到底部控件。
- 上述入口共用的主题、Material 形状、皮肤颜色与玻璃解析；必要的共享调用方回归、语义 / 门禁测试、截图证据和版本记录。

## Out of scope

- v2.4 状态与流式体验、v2.5 动效与快速路径、v2.6 首次引导。
- 全 App 一次性替换所有 `dp`、`RoundedCornerShape`、`Color(0x...)` 或所有 `contentDescription = null`。
- 删除皮肤选项、清除品牌特征、修改用户保存的气泡配置、重排紧凑评论、恢复普通 Chat 入口。
- Room / DataStore schema、Provider 协议、包名、发布版本、`dev.json`、远程崩溃 SDK、系统悬浮翻译或无障碍组件启用。
- 未取得固定真机和可比温控条件时的性能阈值结论；D01 设备效果继续单独登记。

## Acceptance criteria

- [x] A1 / T1：P01 / P02 / P03 的默认形状和布局间距实际来自令牌；几何例外逐项有文件、符号和理由。
- [x] A2 / T2：三种应用主题的浅 / 深和固定动态浅 / 深通过颜色来源及对比检查；Narra 气泡随主题变化，主题切换不复用旧缓存。（受测合成 / 实际渲染样本，异步 URI 加载生命周期未覆盖）
- [x] A3 / T3：13 套皮肤、玻璃开关 / 线上线下组合和 B03 边界通过兼容测试；原始设置在保存回读后保持，图片资源仍由真实加载状态决定。（JVM / 宿主；设备效果另待 D01）

- [x] A5 / T5：新违规样例真实失败、合法与精确例外样例通过；迁移文件清单无遗漏，不增加宽泛白名单。
