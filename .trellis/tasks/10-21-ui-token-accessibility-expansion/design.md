# v2.3 设计令牌与无障碍扩面：技术设计

## 任务结构与顺序

父任务负责需求、共享契约、研究索引和跨批复核，本身不修改产品代码，也不执行 `task.py start`。四个子任务各自拥有 PRD / design / implement / JSONL，按以下顺序实施与验收；批次内部的实现与检查也串行。

| 批次 | 子任务 | 入口边界 | 独立验收产物 |
| --- | --- | --- | --- |
| 1 | [P04 线下扮演与会话阅读（已归档）](../archive/2026-10/10-21-ui-token-offline-roleplay/prd.md) | 相同roleplay/play路由下的线下分支，以及既有会话阅读入口；不包含P14日记 | 两个检查点及共享P03回归已通过，14张E04已接纳，工作提交与归档完成 |
| 2 | [P05 会话设置侧栏](../10-21-ui-token-session-sidebar/prd.md) | 实际设置路由及内部已有 Sheet / Dialog | 侧栏布局 / 语义、成功与失败回调兼容、真实弹层窗口、E05 视觉集 |
| 3 | [P10 设置首页](../10-21-ui-token-settings-home/prd.md) | SettingsScreen 及首页直接弹层 | 首页 / 长文字 / 三种选择弹层、共享设置组件兼容、E10 视觉集 |

## 视觉与无障碍契约

- 默认几何显式消费令牌；图标绘制、边框、insets、用户几何和紧凑评论按用途登记精确例外。源码守卫的范围只扩到本批实际迁移声明，不把未迁移整文件一并“清零”。
- 阅读文字与实际承载面至少 4.5:1，透明内容按真实合成面检查；三主题浅深和固定动态 scheme 都经过生产解析，不能仅对 fixture 颜色取样。
- 应用主题选择优先，保留 13 套皮肤及 12 套品牌特征，已保存圆角 / 宽度 / padding / 尾角 / 玻璃开关原值优先；没有“手调标志”，不得按数值等于旧默认推断迁移。
- 独立动作有名称、角色 / 状态和至少 48dp 命中，装饰不重复朗读。320×640dp、200% 字体下内容能换行 / 滚动，返回、关闭、发送、保存及确认操作可达且不会相互遮挡。
- 对长规则、长地址、长模型名和错误提示做实际布局 / 回调断言；不只把图片好看当作交互通过。既有错误 / 空态仅显示合成状态，不新增业务状态、恢复策略或网络流程。

## 数据与兼容边界

界面继续经现有 navigation / ViewModel / repository 流取得状态。本轮改变显示与语义，不改变 Provider ID / 类型 / API mode、模型能力、设置规范化、凭据存储、会话绑定或角色输入协议。测试使用既有 Fake 和合成 fixture，不连接真实服务或读取用户数据库。

P10 与 P11 当前返回导航在调用 `saveSettings {}` 后立即 `popBackStack`；ViewModel 失败保留草稿且不触发 onSaved。这是现状边界，不能在计划里写成“成功才离页”，也不顺带改变保存 / 导航策略。P05 的具体成功 / 失败链路按 [侧栏研究](research/sidebar-entry.md) 保留。

## 截图扩展方案

采用稳定新增族 E04 / E05 / E10 / E11。每批矩阵详见子任务 design；三主题浅深、固定动态浅深和窄屏大字体分维度覆盖，状态 / 弹层采用代表组合及行为测试补足，不对皮肤、主题、状态做全笛卡尔积。

[公共截图研究](research/coverage-and-queue.md) 定义 before → after → 人工接纳 → verify 流程。新页先验证缺图 actual 能产出，再冻结迁移前证据；缺图失败如实登记，不关闭门禁，不向生产基准 record。若现有工具不产 actual，先实现显式隔离的候选捕获并证明原基准不变。

P05 内部 Sheet / Dialog 和 P11 弹层必须指向真实窗口 root；保留现有 StageTag 主页面路径不变，增量增加窗口目标、真实标题 / 操作 / 尺寸断言。窗口关闭或 root 缺失时测试应失败；只截底层页面不能验收。宿主工具无法稳定捕获时，该视觉项保持未完成，先解决捕获能力再接纳。

每批人工确认后才提交对应新 PNG 与 manifest 新增记录。原有 manifest 并发历史段落修改继续不纳入本任务；旧 78 张哈希及后续各批已接纳图在不受影响时必须不变，任何预期共享变化单独展示。CI 继续 verify，本机通过和远端通过分别登记。

## 风险、回退和延期

- 风险来自共享输入 / 配色、设置组件的广泛消费者和独立窗口捕获。先 fixture / 探针后迁移，按实际声明缩小改动面；任何必要范围扩大先更新规划并重新审阅。
- 单批代码与视觉提交可独立审阅 / 回退；回退只处理该批 diff，不动用户文件、旧任务搬移或已批准的其他批次。
- D01、IME / 系统栏 / 真正玻璃材质及物理性能继续独立待补，宿主结果不代表无性能回归；无设备不强制启动模拟器。
- 世界书、记忆、朋友圈、信箱等仅保留 [后续队列](research/coverage-and-queue.md)，不创建本轮实现子任务。v2.4–v2.6、发版、更新 JSON 与外部发布均不在范围。
