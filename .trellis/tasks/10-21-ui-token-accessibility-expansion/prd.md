# v2.3 设计令牌与无障碍扩面

## Goal

将已验证的默认视觉规则与无障碍能力扩到线下扮演、会话侧栏、设置首页和提供商配置，让用户在大字体或读屏下仍能操作这些入口，并保留个性化设置。按真实入口和共享所有者拆成四个可独立验收的子任务；2026-10-21 用户在最终摘要后回复“可以”，批准四批方案并先启动 P04。

## Background

- 2026-10-21 用户明确授权创建本任务并规划；版本固定为 v2.3，不进入 v2.4–v2.6。
- 试点来源：[扩面清单](../archive/2026-10/10-21-ui-token-accessibility-pilot/research/expansion-list.md)、[验证记录](../archive/2026-10/10-21-ui-token-accessibility-pilot/verification.md)。P01/P02/P03 已完成，两批工作提交为 `67ed7dfb`、`ce710003`；当前试点已归档并记录 journal。
- 试点已有 1642 项 JVM、AndroidTest 编译、Lint、dev 构建及接纳后 79/79 截图通过结果。本轮未改产品，不重复完整测试；新视觉远端 CI、D01 与物理性能仍待补。
- 当前构建配置为 2.2.12-dev；v2.3 未发布。
- 三项入口研究已落盘：[P04](research/offline-entry.md)、[P05](research/sidebar-entry.md)、[P10/P11](research/settings-provider-entry.md)。这些研究含源码锚点和覆盖缺口，不把源码风险当作已复现缺陷。公共截图与后续排期见 [coverage-and-queue.md](research/coverage-and-queue.md)。

## Requirements

- E1：按 P04 → P05 → P10 → P11 串行推进，各子任务独立实现、检查、视觉接纳与提交归档；父任务只协调共享契约和跨批验收。共享文件每批只有一个修改者。
- E2：四批实际消费既有 `NarraUi` 六档间距、`NarraShapes` 四档形状与成对语义色；P04 包含会话阅读，P05 包含八个局部页及内部窗口，P10 包含首页三种外观 Sheet，P11 包含列表 / Config / Models 和实际弹层。
- E3：保留全部 13 套皮肤、品牌精确例外、用户气泡几何 / 尾角 / 玻璃开关与存储原值；不因旧值等于默认而改写。共享设置组件以显式参数 opt-in，未迁移调用方默认不变。
- E4：三主题浅深和固定动态浅深跟随实际生产解析；阅读文字按实际合成面至少 4.5:1。独立动作有名称 / 角色 / 状态、至少 48dp 命中，320×640dp / 200% 字体下主要操作不遮挡且可滚动到达；以真实布局 / 回调证明。
- E5：新增 E04 14、E05 18、E10 16、E11 32，共 80 张候选，分别审阅；保留当前 78 张及既有 ID / 零像素门禁。窗口截图捕获真实 Sheet / Dialog，不能仅截底页；缺图 / 零测试失败继续生效，人工确认后才接纳并 verify。
- E6：保留各入口保存、回调、导航、发送 / 滚动、Provider 协议 / ID / 模型行为；不把 P10/P11 当前立即 pop 返回写成保存成功才离页。P05 保存失败只验证现有留稿 / 留页回调，不新增未接线的错误视图。Fake / fixture 不读用户数据或调用真实服务。
- E7：世界书、记忆、朋友圈、信箱等仅做后续 v2.3 视觉 / 无障碍排期；功能状态、流式、动效、引导不随本任务实施。规划文档和上下文齐备后展示最终摘要，获批后仅按序启动子任务，父任务不启动；实现 / 检查默认派对应 Trellis 子代理。

## Out of scope

- 父任务本身不改产品代码，产品实施在获批子任务范围内进行；新基准仍需逐批人工视觉确认，不重走已批准试点规划。
- 不接手历史专项，不恢复旧任务，不覆盖无关修改。
- 不改发布版本、`dev.json`、构建渠道，不发包、不推送。
- 不恢复普通 Chat / Translator 日常入口，不改 Provider 协议、存储 schema 或凭据。
- 不以宿主测试或模拟器取代 D01 / 真机性能结论。

## Decisions and remaining limits

范围 / 产品方向已由本次用户要求与试点统一方向限定，无需再次确认试点提交或制造额外产品问题；最终摘要已由用户回复“可以”批准，先启动 P04 子任务。技术上先用新增用例探针验证缺图 actual 与真实窗口捕获，未证实时阻断对应视觉验收而非伪造页面。P05 未接 Settings 保存错误消息 UI、P10/P11 返回立即 pop 均保留现状；新视觉 CI、D01 与物理性能继续待补。
