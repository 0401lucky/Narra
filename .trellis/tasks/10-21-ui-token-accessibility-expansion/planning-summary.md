## 验收与关键决定

- 默认几何实际消费 NarraUi / NarraShapes；三主题浅深及固定动态 scheme 走生产解析，实际文字承载面对比至少 4.5:1。
- 主要动作有有效名称 / 角色 / 状态、至少 48dp 命中；320×640dp / 200% 字体下可到达且不遮挡，真实布局与回调验证独立于截图。
- 全部 13 皮肤、用户原值几何 / 尾角 / 玻璃与品牌特征保留。SettingsComponents 只有一个修改者，显式 opt-in，其他消费者默认不变。
- P04 含会话阅读，不含日记；P05 是路由面板，其内部弹层才是独立窗口；P11 不迁移独立全局模型设置页。保存 / 退出策略维持各入口现状。
- 实现 / 检查默认用对应 Trellis 子代理。父任务只协调，先启动 P04 子任务；每批验收失败先修本批，不越批掩盖。
