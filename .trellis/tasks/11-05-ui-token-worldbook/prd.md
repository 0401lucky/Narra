# v2.3 扩面五：世界书与数据导入导出

## Goal

将世界书管理及共享数据导入/导出页扩入未发布v2.3的设计令牌与无障碍契约，使列表、书目详情、条目编辑和数据迁移界面在长文本、320×640dp / 200%字体下仍能阅读和操作，保留现有世界书与数据读写行为。

## Background

- 用户在P11及四批父任务完成后同意创建P06；2026-11-06在最终规划摘要后回复“ok”，明确批准实施，已启动现有任务。
- 用户随后明确选择“同时迁移共享数据页”，将ContextTransferScreen整页及直属界面纳入；不限于其中世界书分组，不扩展到其他资料所属模块的独立页面。
- 来源为[已归档扩面后续队列](../archive/2026-11/10-21-ui-token-accessibility-expansion/research/coverage-and-queue.md)，新任务独立承接，不重启已归档父任务。
- 起点为`main / 43ebda6d`，已有111项历史状态与manifest旧CI差异保留。当前158张已接纳PNG、159截图及1826 JVM结果属于已完成前序，不作P06实施通过证据。
- 构建与更新配置保持2.2.12-dev；不推送、不发包，不进入v2.4–v2.6。

## Requirements

- W1：覆盖真实世界书列表、书目详情、条目编辑/关键词/全屏正文和共享ContextTransfer整页；包含备份、角色、世界书、记忆、预设五组、页内预览以及直属帮助/确认/来源Dialog和编辑Popup。保留“我→资料库”及角色扩展/会话入口，不恢复SettingsScreen中只有签名的隐藏入口。
- W2：实际消费NarraUi/NarraShapes与Material语义配对，主要文字与真实承载面至少4.5:1；320×640dp/200%下长标题、筛选、字段/关键词、首末项、保存/取消及导入导出操作可读可达，实际touch至少48dp且相邻独立动作不串。只读信息保持无点击，错误/忙碌仅呈现已有状态。
- W3：保留世界书/条目ID、bookId/来源名称、未编辑字段/extras及既有规范化，分组/排序/搜索/三维筛选不变。保留编辑保存/删除立即返回、返回不保存、无VM编辑草稿及现有消息过滤；全屏确认仅回写正文草稿，取消不回写；不扩大试命中语义或新增未保存确认/错误恢复。书目删除仍等实际条目变空再退出。
- W4：所有截图和行为以固定数据/Fake隔离用户库、真实文件/凭据/网络；63个新E06场景先取得完整真实before，再同参数after并验证稳定。原158张及缺图/计数/零像素门禁保留；新视觉和具体提交分别人工审阅，任何来源修正有原始提交与哈希证据。
- W5：规划形成PRD/design/implement及真实JSONL上下文，核心规范与读取索引完整注入，详细研究按检查点必读；按共享接入、列表/详情、编辑、资料库串行检查点，统一共享文件与Gradle所有权。最终摘要获后续明确批准后才启动实施。
- W6：共享数据页保留5种section/文件名、3类系统选择器和null取消、URI读写/安全上限/脱敏、页内notice/前5冲突/确认取消、既有busy范围。确认中头像应用/合并被捕获的失败保留预览，但不承诺成功合并后计数刷新失败、导出生成失败的额外恢复或跨DB/媒体/Settings原子回滚；不改变格式识别、合并/预设/头像/权限或从世界书入口自动预选的规则。

完整现状与源码锚点分别见[列表/详情](research/entry-list-detail.md)、[编辑与数据身份](research/editor-contracts-tests.md)、[共享资料库](research/context-transfer.md)；技术方案、API兼容和矩阵见[design.md](design.md)。
