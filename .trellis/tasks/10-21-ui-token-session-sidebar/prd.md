# v2.3 扩面二：会话设置侧栏

## Goal

将真实会话设置侧栏及其现有弹层扩入 v2.3 默认令牌与无障碍契约，让长规则、窄屏大字体和个性化设置可操作。当前只规划，归属 [扩面父任务](../10-21-ui-token-accessibility-expansion/prd.md)，在 P04 验收后串行实施。

## Background

[P05 研究](../10-21-ui-token-accessibility-expansion/research/sidebar-entry.md) 核实唯一链路为 RoleplayNavGraph → Screen → Content → SidebarContent。本体为普通路由内的自适应右侧面板；仅内部 Sheet / AlertDialog 是独立窗口。现有局部设备测试不等于整页 200% 或设备运行通过，尚无 P05 截图登记。

## Requirements

- S1：MAIN / SCENE / IDENTITY / GROUP / THEME / QUICK / VISUAL / REGEX 的默认外壳、间距、控件 / 选项语义采用现有令牌；保留 94% / 66% / 最大 480dp 宽度算法和 insets。
- S2：八页在 320×640dp / 200% 字体下可进入、滚动和返回；长说明、模式选项、末项及危险操作可达。主要动作有名称、角色 / 状态与至少 48dp 命中，帮助 / 行 / Switch 不互相触发。
- S3：全部 13 皮肤、用户几何 / 尾角 / 玻璃开关、完整对象保存和预览保留。主题默认卡外壳使用令牌，预览内用户几何仍优先；重置仅按原动作范围执行。
- S4：保留全局草稿成功保存才离页 / 进入阅读、失败 callback=0 且保留草稿；场景预设 / 面具 / 视觉的即时回调、模型选择保存时机不变。当前缺少 Settings message 展示接线，本批不伪造错误面板或新增保存流程。
- S5：现有 Sheet / Dialog 用实际入口打开，选择、取消、确认 / dismiss 语义不变；新增真实独立窗口捕获能力，不能截底层页面充数。
- S6：新增 E05 18 张候选、真实行为与精确源码守卫，用户接纳后 verify；受影响 P03/P04 与设置共享调用回归通过。

## Acceptance Criteria

- [ ] SA1 / S1/S2：八页实际布局、200% 字体、读屏状态 / 标签、48dp 和回调断言通过；系统返回按现状回归，不假定等同顶部返回图标。
- [ ] SA2 / S3/S4：13 皮肤可选、原值保存回读、重置范围、成功 / 失败与场景即时回调兼容；失败不冒称已持久化或新增 UI 提示。
- [ ] SA3 / S5：预设 / 面具 / 模型、说明、成员、重启 / 重置实际窗口有行为证据；窗口缺失时捕获用例失败，确认与关闭严格分离。
- [ ] SA4 / S6：18 张 E05 视觉人工确认，旧图与新图全部 verify；源码守卫和受影响检查通过，设备 / CI / 性能缺口准确登记。
- [ ] SA5：P03/P04 返回面与必要共享调用回归通过，本批可独立提交 / 回退，更新版本记录及必要 spec。

## Out of scope

- 不启用未挂载的 RoleplaySettingsHero，不新增错误 / 重试 / 自动保存 / 系统返回策略，不整合场景与全局设置为新事务。
- 不整体改 SettingsComponents、公共玻璃或 ModelPickerSheet；必要共享修正须登记所有消费者并限定单一所有者。
- 世界书 / 记忆领域功能、发版、`dev.json`、v2.4–v2.6。
